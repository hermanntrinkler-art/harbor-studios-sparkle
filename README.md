# Harbor Studios

Creative digital studio building AI-powered apps, PWAs and immersive games.

This repository contains the Harbor Studios portfolio website.

## Tech Stack

- React 18 + TypeScript
- Vite
- Tailwind CSS + shadcn/ui
- react-i18next (DE, EN, ES, FR, IT, PT)
- React Router

## Development

```sh
npm install
npm run dev
```
